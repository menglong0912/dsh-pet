# 历练：秘境、试炼、奇遇（设计草案，2026-10-26）

修炼 X0–X9 落地后，用户反馈「提升修为太单一，没有互动感」。本文规划第二期内容：**秘境（副本）**、**试炼**、**奇遇**，参考《鬼谷八荒》。方向拍板后，再按 `cultivation-roadmap.md` 的格式拆成任务书。

- **状态**：方向已拍板（§8），数值都是起点，要用模拟和真机再调。心魔的改动（§7.3）已经落进代码。
- **路径**：下文代码路径都相对包目录 `dsh-pet/`。
- **前提**：`cultivation-battle-research.md` §3 的约束和 §6 已拍板的各项（不做体力、输了不受罚、单机完整、修为来源不上网）继续有效，只有一条改了：**秘境和心魔的收益不再每天封顶**（§7）。本文只写新增和改动。

## 1. 结论先说

1. **现在单一在哪**：修为九成来自「在电脑前」（每天 240），主人什么也不用做；能主动点的只有心魔试炼（每次都打自己的影子），渡劫要几天到几十天才碰上一次，切磋又得有邻居。主人想参与也没有可做的选择。
2. **补的是「选择」，不是「操作」**。对战照旧全自动，新增的互动都是有后果的选择：走哪条路、要不要冒险、带哪几件法宝上场、奇遇里怎么应对。一次选择几秒钟，选完看宠物自己打。这和桌宠「主人在干活」的前提合拍，也不违背已拍板的「只做全自动」。
3. **从鬼谷八荒借三样**：
   - **秘境**：进去打妖兽、开宝箱、最后打守护兽；
   - **奇遇**：一段小故事加两三个选项，有的选项过几天才见分晓（它的「约定」）；
   - **破境要准备**：突破大境界前，先去秘境找破境材料；元婴起的大劫分心魔劫和雷劫两段。

   另外借**天骄**做「试炼」：每个大境界一位有名有姓、打法各异的对手，替掉「永远打自己影子」的单调。

4. **秘境做成一张小节点图**（借杀戮尖塔的分岔路线）：一趟 5 步，手动走 3–5 分钟，**气血跨场保留**，所以「回血还是贪宝箱」「打不打精英」都是真取舍。输了只是这一趟到此为止，已经拿到的照拿。八个秘境各取一部小说的名场面（血色禁地、滴血洞、三王传承、天焚炼气塔、火焰山、荒古禁地、鬼邮局、诛仙阵），规则尽量照原著（§4.3）；第一个血色禁地的完整设计见 §4.9。
5. **能托管**：主人忙的时候，宠物自己闯，约 5 分钟走一步；桌面上只有一张不挡鼠标的「神游小卡」显示进度，不打断干活（§4.8）。
6. **收益不封顶，靠「时长」控制节奏**：秘境、心魔都是打一场算一场。为了不让连点快进刷爆，秘境的赶路不能跳过、低境界的秘境收益打折；心魔的收益随间隔恢复，隔满 10 分钟才是满额（§7.3）。按目标节奏，只挂着的人不变；开托管，节奏约是原来的 2 倍；再每天手动玩半小时到两小时，约是 2.5 到 4 倍（§7.1）。
7. **尽量有画面**（§9）：秘境有封面、地图、每个节点的插画；每只妖兽和守护兽都有自己的动画；奇遇每条配一张插画；宠物新增 8 段秘境动作。第一期约 **4 600 积分**，现有余额 7 180 够用；三期全做完约 **13 600 积分**（§10）。建议先只拿血色禁地试点，约 1 800 积分。

## 3. 约束（在调研 §3 之上新增的）

- **一次几秒的决定**：任何一步选择，主人看一眼就能决定；不选也不卡死（超时有默认选项，或者能挂着下次接着走）。
- **不主动打断干活**：手动秘境和天骄只在主人点了以后才开始；托管只有一张不挡鼠标的小卡，冒泡很少（§4.8）。日常奇遇只在主人**离开电脑回来**时才可能出现（活动统计的 `return` 事件），一天最多 2 次，碎碎念让路的那些情形照样让路。
- **不做每日清单**：没有签到、连续登录，也没有「今天还没做」的提示。
- **不能刷着重来**：每一趟秘境、每一场战斗的结果都由存档里的种子决定，**先记账再演出**（同 X5 切磋）。中途关 app，重开还是同一个结果。
- **右键菜单只多一项**：现在已经快到宿主 20 项的上限（`MENU_ITEMS_MAX`）。新内容都放进一个「历练」小窗，菜单只多一项「修炼/历练」。
- **代码组织**：`features.ts` 已经 2644 行。新逻辑都放进新的纯逻辑模块，并配单测：`dungeon.ts`（地图生成、节点结算）、`encounters.ts`（奇遇库）、`rivals.ts`（天骄名册）。`features.ts` 只做接线。

## 4. 秘境（副本）

### 4.1 一趟怎么走

```text
第 1 层     第 2 层      第 3 层      第 4 层      守护
 [妖兽]──┬─[宝箱]──┬──[灵泉]──┬──[精英]──┐
         │         │          │          ├──[守护兽]
 [奇遇]──┴─[妖兽]──┴──[ ？ ]──┴──[遗迹]──┘
```

- **结构**：4 层，每层 2–3 个节点，最后是守护兽。每次只能走到和当前节点相连的下一层节点，一趟一共 5 步。下一层能看清，再往后的节点是「？」（借鬼谷八荒的迷雾）。
- **气血跨场保留**：进秘境时满血，之后每一场接着上一场剩下的血打，只有灵泉和部分奇遇能回。这是整套秘境的取舍来源。
- **随时能撤**：撤了就带着已经拿到的东西出来。
- **输了**：这一趟到此为止，已经拿到的照拿；**不扣修为、不丢东西**（「输了不受罚」）。损失只是没拿到守护兽那一份。
- **能挂着**：关掉小窗或者退出 app，进度留在存档里，下次从菜单「修炼/历练」接着走。一趟进了 24 小时还没走完，就按撤退结算。
- **时长**：手动走 3–5 分钟一趟：每一步赶路约 15 秒（**不能跳过**，§7.2），4 场小战每场约 10 秒，一场完整的守护兽战约 1 分钟。

- **对手属性**：按你**当前的小境界**用典型成长推出来，但不超过本秘境的上限（炼气的秘境封在炼气九层）。小怪 ×0.8、精英 ×1.0、守护 ×1.15，再配上它自己的招式。这样在本境界里一直有挑战，回低境界的秘境就很轻松（所以收益打折，§4.7）。

### 4.4 秘境加持（借「逆天改命」）

遗迹节点给三个加持，挑一个，**只在这一趟有效**，不进长期存档，所以不会让成长膨胀。例子：

| 加持     | 效果                       |
| -------- | -------------------------- |
| 灵泉余韵 | 之后每场开打前回 10% 气血  |
| 借剑     | 这一趟多一件随机的灵器法宝 |
| 妖丹     | 灵力 +3                    |
| 身轻如燕 | 闪避 +6%                   |
| 背水一战 | 气血低于三成时，伤害 ×1.3  |
| 寻宝鼠   | 守护兽的掉落多一份         |

第一期 8–10 个。引擎这边只是在开打前改一下 `Fighter`，或者加一个结算修正，不新增事件类型。

### 4.5 唯一的「备战」：带哪几件法宝

- **规则**：打守护兽和天骄之前，小窗里列出对方的打法和自己所有法宝，主人挑最多 3 件带上场；不挑就全带（和现在一样）。
- **为什么只加这一项**：法宝现在是每次出手从自己的法宝里随机挑一件。挑法宝针对的就是对方的打法，比如对分身流带必中的烟花、对冻人的带远程。这是全自动战斗下代价最小、又最有意义的一个决定。引擎不用改，传进去的 `weapons` 少几件就行。
- **不做装备栏**：只有打守护兽和天骄的那一场要挑，打完不留。托管时不挑，全带。

### 4.6 怎么演

- **速战（小怪、精英）**：一场约 10 秒，只演开场、伤害最大的一下、收场三拍，气血条照走。小窗里有「完整演出」开关，默认关。
- **完整（守护兽）**：沿用 X3 / X7 的时间线和特效层，约 1 分钟，可以快进。
- **妖兽怎么上桌面**：妖兽每只都有自己的动画（§9.3），用客人窗口播，`openGuestWindow` 加一种不改色的配色 `'none'`。摆位、`foeStage`、特效层都照旧，时间线发来的动画名换成妖兽自己的素材名。
  - 妖兽的首尾帧就是它的立绘，所以动画之间、动画和静态立绘之间切换都不跳；
  - 哪段动画缺了，就退回立绘加 CSS 动作：出手扑一下、受击抖动闪红、闪避侧移、倒地倾倒淡出。
- **妖兽的攻击**：用特效层飞过来（爪痕、火球……），命中时刻由程序计算，同 X7。
- **小窗**：开打时缩成一条，打完再展开，免得挡住战斗。

### 4.7 收益

收益**不封顶**，打一趟算一趟（§7）。数值是起点，按 §7.1 的目标节奏用模拟反推。

| 来源             | 修为（各秘境一样） | 其他                                                                                          |
| ---------------- | ------------------ | --------------------------------------------------------------------------------------------- |
| 妖兽             | +4                 | ——                                                                                            |
| 精英             | +7                 | 30% 掉一件还没有的法宝                                                                        |
| 宝箱             | +3–6               | 15% 破境丹                                                                                    |
| 守护兽           | +12                | 必掉一份：法宝、**功法玉简**（15%，复用 X4 的二选一 `offer`，领悟一门还没学的招式）或破境材料 |

- **为什么各秘境给的修为一样**：「陪主人」那份也不随境界涨（每分钟 +1），秘境要是越往上给得越多，§7.1 的每天目标就对不上。高境界秘境的好处在掉落和更难的对手。

- **破境丹**：多一个来源，不怎么用 Claude 的主人也能攒到。

### 4.8 托管

- **开关**：历练小窗里点「托管」。之后宠物自己一趟接一趟地闯，主人点「接手」或者打开小窗就能随时接过来。
- **节奏**：约 5 分钟走一步，一趟约 25–30 分钟，一小时大约两趟。
- **跟着健康规则走**（同「陪主人」的修为）：
  - 只在主人在电脑前时走，离开就停在原地；
  - 久坐提醒响过、主人还没起身（心浮气躁）时也停，冒泡「我也歇会儿，等你起来活动一下」；
  - 0–4 点不走。
- **它怎么选**：
  - 岔路：气血低于一半就去灵泉，否则宝箱 > 妖兽 > 精英；
  - 奇遇：选最稳妥的那个选项；
  - 遗迹：随机挑一个；
  - 守护兽：不挑法宝，全带。

  托管的通关率因此低于手动，这就是「亲自带」的好处，不另设惩罚。

- **桌面上**：一张「神游小卡」（§9.4），不挡鼠标，宠物照常做自己的日常动作。战斗在后台结算，小卡里用立绘演一个简版；守护兽那一场打完可以在小窗里「回放」（种子都在，重算一遍时间线就行）。
- **冒泡**：只说要紧的事（打赢守护兽、掉了法宝或玉简、一趟走完），至少隔 10 分钟一次。日记每趟记一条。
- **让路**：打心魔、渡劫、切磋、有客人来时，托管先暂停，结束后接着走。

## 5. 奇遇

### 5.1 一条奇遇长什么样

```ts
{
  id: 'hurt-fox',
  when: { minStage: 0, where: ['daily', 'dungeon'] },
  art: '奇遇-受伤的灵狐',
  text: '路边草丛里有只受伤的灵狐，正警惕地看着你。',
  choices: [
    { label: '给它包扎', cost: { hpShare: 0.1 }, outcome: { foreshadow: 'fox-repay' } },
    { label: '试着收服', check: { stat: 'agility', dc: 12 }, win: { blessing: 'spirit-fox' }, lose: { xp: 5 } },
    { label: '悄悄走开', outcome: {} },
  ],
}
```

- **判定**：按属性判定（身法躲、灵力打、遁速追），成功率写在选项旁边，比如「（身法，约 60%）」，让主人知道自己在赌什么。
- **伏笔**（借「约定」）：有的选项当时什么都不给，一到两天后才兑现。比如包扎过的灵狐某天叼来一件法宝，宠物冒泡「之前救过的那只灵狐来报恩了！」，配一张报恩插画。伏笔只会是好事，**没有借鬼谷八荒「没完成就扣气运」那一半**。
- **规模**：第一期约 20 条，每条一张插画（§9.1）：每个秘境 4 条专属（按原著名场面写，血色禁地的见 §4.9），日常 8 条。
- **台词**：全用模板，不调模型。

### 5.2 日常奇遇

- **什么时候出**：主人离开电脑 ≥ 5 分钟后回来，30% 概率；一天最多 2 次。正在演出、出门串门、家里有客人、在看屏幕，这些时候都不出。设置页有开关，默认开。
- **怎么问**：宠物冒一句开头，旁边弹一个小选择窗：上面是奇遇插画，下面两三个选项（照 `note-window.ts` 的做法：要能拿焦点，`executeJavaScript` 等结果）。2 分钟不选就按最后一项（「走开」那种）算，冒泡「那就算了～」。
- **收益**：每次 +10–40 修为、破境丹，或者给下一趟秘境带一个加持；少数会掉法宝。

### 6.2 破境试炼（改造现有渡劫）

- **破境材料**：每个秘境的守护兽有机会掉落本境界的破境材料，比如血色禁地的「筑基丹主药」（§4.9），进筑基时用。渡劫时自动用上，效果是这一场天雷伤害 −15%，可以和破境丹叠加。
  - **不卡进度**：没有材料照样能渡劫，只是更难一些。这样只挂机的人不会被卡住，进秘境的人渡劫更稳。
- **大劫两段**（借元婴劫）：
  - 从进元婴开始，渡劫先打心魔劫，再扛雷劫；
  - 心魔劫就是现有的心魔试炼战，心魔这次 ×1.0；
  - 心魔劫输了等于渡劫失败，扣修为的规则不变（20%，最多 300）；
  - 不需要新素材。要重标渡劫平衡：两段合起来，不吃丹的成功率仍是 0.6–0.7。

## 7. 数值与节奏

### 7.1 目标节奏

收益不封顶以后，修为涨多快主要看「玩了多久」。先定目标，再用模拟反推每趟给多少：

| 怎么玩                     | 每天修为（约） | 进大乘（约） |
| -------------------------- | -------------- | ------------ |
| 只挂着（不进秘境、不托管） | 300            | 385 天，不变 |
| 开托管（在电脑前 6 小时）  | 600            | 190 天       |
| 托管 + 每天手动玩半小时    | 750            | 155 天       |
| 托管 + 每天手动刷 2 小时   | 1 200          | 95 天        |

- **怎么算的**：从炼气一层到进大乘一共要 115 350 修为（调研 §4.2 的境界表）。§4.7 的数值让托管约每小时 +50（一小时两趟），手动约每小时 +350（4 分钟一趟）；手动的那段时间不算托管。
- **天然的刹车**：大境界圆满后修为就停住，要渡劫才能继续。刷得再快，每个大境界也要过一次渡劫。
- **切磋、调息、陪主人**：都不变，切磋仍是每天前 3 场有收益。

### 7.2 秘境怎么防刷

- **赶路不能跳过**：快进只压缩战斗，每一步约 15 秒的赶路照走，手动一趟至少约 2 分钟。
- **低境界打折**：见 §4.7。
- **结果由种子定**：退出重开不会换结果（§3）。

### 7.3 心魔：收益不封顶，随间隔恢复（已落地）

- **已改**（2026-10-26，`cultivation.ts` 的 `trialDone`）：
  - 不再只算当天第一场，场次和总量都不封顶；`today.trial` 改成「今天打了几场」；
  - 收益随离上一场的间隔线性恢复，隔满 10 分钟给满额（赢 +30、输 +10，赢了 30% 掉一件还没有的法宝）；不满 10 分钟时，修为和掉落概率都按比例打折，修为向下取整；
  - 一分钟一场正好 +3，不到 20 秒一场就一点没有；不管多久打一场，一小时最多约 +180；
  - 上一场的时刻存进存档的 `trialAt`（旧档没有就当没打过），重启不清零；时钟往回拨过就按间隔 0 算；
  - 没恢复满时多一条事件 `trial-tired`，宠物冒泡「心魔还没缓过来，这一场收益打了折；再过 N 分钟打才是满额」。
- **为什么要这样**：心魔能快进。点「心魔试炼」、再点「快进」，一场 10 秒左右，平均每场约 +22（对心魔胜率 55–70%）。不加限制的话一小时能刷到约 8 000，是挂一整天的 25 倍多，法宝十来分钟就能收齐。
- **当时比过的三个办法**（用户选了 B）：

  | 办法                          | 怎么做                                                                       | 代价                                  |
  | ----------------------------- | ---------------------------------------------------------------------------- | ------------------------------------- |
  | A. 不管                       | 就照现在                                                                     | 节奏完全由主人自己把握                |
  | **B. 收益随间隔恢复**（建议） | 距离上一场越久给得越多，隔满 10 分钟给满额；不限场次、不限总量，只是连点没用 | 一小时最多约 +180，要多一行说明       |
  | C. 快进的场次不给修为         | 看完整场才给                                                                 | 看一场约 1 分钟，一小时仍能刷约 1 300 |

### 7.4 平衡目标

`scripts/dev/battle-sim.mjs` 加秘境模拟：

- 同境界典型成长，满血打：小怪胜率 85–90%、精英 65–75%、守护兽 55–65%；
- 一趟通关率：手动（模拟里按「血低于一半就去灵泉」走）本境界 45–60%；托管的走法约 35–45%；低一个大境界 ≥ 90%；
- 天骄：刚进该大境界时首战胜率约 35–45%，后期约 65–75%；挑对法宝时胜率高 10–15 个百分点，**挑法宝要真有用**；
- 任何一个加持，持有方的通关率提升不超过 15 个百分点；
- 托管每小时、手动每小时的修为落在 §7.1 的目标上下 20% 以内。

   - 进秘境时播这个秘境的入口过场（5 秒小视频），之后停在封面；
   - 每走到一个节点，就换成这个秘境里这种节点的插画（血色禁地里的采药、山洞调息……），切换时淡入；
   - 宝箱有「关着」「打开」两张，开箱时切过去，掉落的图标从箱子里弹出来（CSS）。
2. **地图**：这个秘境的手绘地图做底，节点图标钉在上面，走过的路亮起来；宠物的 Q 版小头像沿着路走过去（CSS 动画，正好占满那 15 秒赶路）。
3. **状态条**：气血、本趟的加持（卡面图标）、本趟的战利品。
4. **操作**：岔路就是点地图上的节点；奇遇的选项、遗迹的三张加持卡、守护兽前挑法宝（法宝图标），都在这一块。

### 9.3 妖兽、守护兽、天骄的动画

- **怎么做**：先用 `text2image` 在纯绿底上画出立绘（朝左、粗描边，贴近现有画风），再用 `frames2video` 以立绘作首尾帧生成动作，抠像流程同宠物素材。首尾帧都是立绘，所以「动画 ↔ 静止立绘」切换不跳。
- **每只做哪几段**：

  | 角色               | 立绘                      | 动作（每段 4 秒，绝招 5 秒）                                         |
  | ------------------ | ------------------------- | -------------------------------------------------------------------- |
  | 小怪（每秘境 3）   | 1 张                      | 出手、受击、倒地；起手和闪避用立绘加 CSS                             |
  | 精英               | 复用小怪                  | 复用小怪的动画，放大 1.2 倍、加一圈金边                              |
  | 守护兽（每秘境 1） | 桌面 1 张 + 登场大图 1 张 | 起手（吼）、出手、绝招、受击、倒地                                   |
  | 天骄（8 位）       | 桌面 1 张 + 榜单大图 1 张 | 起手（抱拳）、出手（通用甩出）、施法（通用）、受击、闪避、倒地、胜利 |

- **飞行物**：每个秘境约 7 张贴图（3 种小怪的攻击、守护兽的普攻和绝招、2 种命中特效），长边 256、朝左，描边同现有特效的黑 / 深藏青。

### 9.4 神游小卡（托管时）

- **样子**：宠物旁边一张约 200×130 的小卡，透明、置顶、不可聚焦、不挡鼠标（同擂台窗口），显示：
  - 当前节点插画的缩略图；
  - 5 个进度点；
  - 气血条。
- **打怪时**：缩略图上叠妖兽的立绘，用 CSS 抖一抖、气血条往下走，打完立绘淡出。
- **其余时候**：宠物照常做自己的日常动作；进秘境时播一次「修炼-打坐」，表示神识出窍去了。

### 9.5 奇遇插画

- **每条一张**：16:9，画的是那个场景（受伤的灵狐、无字碑、两只妖兽打架……）。
- **结果图**：部分奇遇的成功或失败另配一张。
- **伏笔兑现**：每种兑现一张（灵狐叼着法宝来报恩……）。

### 9.6 图标与卡面

- **节点图标**：7 个。
- **加持卡面**：10 张。
- **法宝图标**：大多复用现有的飞行物贴图（扑克牌、毽子、雪球、托盘……），水枪、鲸尾、弹弓这几件要补。
- **破境丹、破境材料**：各一个图标。
- **宠物 Q 版头像**：地图上用。

## 12. 想法池（先不排期）

| 想法             | 说明                                                                                                             |
| ---------------- | ---------------------------------------------------------------------------------------------------------------- |
| 秘境地台         | 秘境里开打时，在两只脚下铺一条场景地台（禁地山林、石殿石板）。要一个排在宠物窗口下面的窗口，层级能不能稳住要先试 |
| 天骄换成各书人物 | 天骄榜也照名场面的思路，换成各部小说里的人物（同辈天才），打法照原著；要先逐个核对原著                           |
| 问道塔           | 无尽层数，记最高层，每 5 层首通给一次奖励（大乐斗斗神塔）                                                        |
| 守护兽手动选招   | 引擎已经留了 `Controller`；只给守护兽和天骄战开，每回合从 2–3 个招式里点一个                                     |
| 结丹品相         | 进金丹时三选一（偏灵力、身法或遁速），决定之后成长的偏向（鬼谷八荒结金丹）                                       |
| 组队秘境         | 局域网里的邻居一起进一趟，各打各的场次、共享守护兽（Habitica 式）                                                |
| 秘境专属法宝     | 每个秘境一两件只在那里掉的法宝；要升 `BATTLE_VERSION`                                                            |
